# Provenance and limits

This independent instruction-only pilot summarizes general workflow principles
from the public `zedarvates/frugal-skills` project (MIT). It does not copy or
redistribute the 115 catalog entries or any third-party licensed code.

The parent project's THIRD_PARTY_NOTICES.md lists unresolved provenance for
some catalog entries. Those entries are not bundled in this plugin.

This archive contains no credentials, executable scripts, MCP server, telemetry,
payment handler, or autonomous execution feature. It makes no measured savings claims.
